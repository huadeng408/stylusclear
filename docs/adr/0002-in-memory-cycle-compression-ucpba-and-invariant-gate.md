# ADR-0002：WASM 内存态先环路压缩后批量拍卖与三不变量原子门禁

* **状态**：已采纳（Accepted）
* **日期**：2026-11-17
* **关联术语**：`清算批次`、`义务有向图`、`多边环路压缩`、`统一出清价格`、`批量拍卖出清`、`资产守恒`、`限价个体理性`、`健康度单调性`、`原子拒止回滚`（见 [`CONTEXT.md`](../../CONTEXT.md)）

## 背景与问题

根据 [Arbitrum 官方 Stylus 性能基准报告](https://blog.arbitrum.foundation/rust-onchain-a-backend-engineers-guide-to-stylus/) 与 [Stylus 架构指南](https://docs.arbitrum.io/stylus/gentle-introduction)，Stylus 相较于传统 Solidity EVM 的核心成本优势集中在**内存密集与循环迭代计算**，而持久化存储（`SLOAD` / `SSTORE`）在两个虚拟机上的开销基本持平。同时，[Stylus 二进制体积规范](https://docs.arbitrum.io/stylus/how-tos/optimizing-binaries) 要求单合约未压缩 WASM 不超过 `128 KB`、Brotli 压缩后不超过 `24 KB`（免分片直传上限）。若沿用传统链上逐笔撮合写库模式，存储开销将淹没 WASM 计算红利；若引入重型图算法第三方库，则易突破 `24 KB` 压缩红线。

## 决策内容

1. **“单次读入 → 纯内存两阶段清算 → 净额差值一次性落盘”流水线**：
   * **阶段一（确定性 `多边环路压缩`）**：在 WASM 线性内存中构建按账户索引升序排列的静态邻接结构，采用确定性深度优先搜索（Canonical-Order DFS）枚举并消解同资产 `债务环路`，每次沿环路瓶颈边权重同步扣减各边应付额，直至图内无有向环。此步骤无需动用任何新增流动性即可释放被三角/多角债务锁死的保证金占用。
   * **阶段二（离散格点 `统一出清价格` `批量拍卖出清`）**：收集当批全部合格 `交易意图` 的申报限价与 `参考标记价格` 构成候选价格集合，在内存内计算各候选价下的累计买量与累计卖量：
     * 选取最大化可成交量的价格作为 `统一出清价格`；
     * 若存在多个价格同达最大成交量，选取最小化买卖不平衡度、且最贴近 `参考标记价格` 的唯一确定性中位价格，杜绝矿工/排序器操纵空间；
     * 当供需不完全相等时，足额侧按 `交易意图` 限价优度与确定性提交序号分配成交额。
   * **最终落盘压缩**：合并阶段一与阶段二的账户各资产变动，仅对净变动非零的 `(账户, 资产)` 槽位执行一次存储写入。
2. **三不变量 `原子拒止回滚` 终审门禁（Post-Clearing Invariant Gate）**：
   在把内存态净变动刷入合约存储前，强制顺序核验：
   * **I1 `资产守恒`**：对批次涉及的每一资产 $\sum_{i} \Delta \text{Balance}_{i, a} + \Delta \text{FeeVault}_{a} == 0$；
   * **I2 `限价个体理性`**：对每一笔获得非零成交的买单 $P_{\text{clear}} \le P_{\text{limit}}$，卖单 $P_{\text{clear}} \ge P_{\text{limit}}$；
   * **I3 `健康度单调性`**：对每一发生新开仓交易成交的 `参与账户`，清算后折后有效抵押净值必须满足 `初始保证金要求`；对仅参与环路压缩或减仓的账户，清算后 `账户健康度` 不得低于批次前水平。
   任一断言失败即丢弃整块内存工作区并返回具体违例错误码，链上存储零修改。

## 权衡与后果

* **正面收益**：将 $O(V \cdot E)$ 图环路消解与 $O(N \log N)$ 拍卖寻优完全收敛于廉价的 WASM 线性内存内，实测重计算部分较同构 Solidity 节省显著 Gas，同时手写紧凑图结构使核心库保持零重型外部依赖，轻松满足 `< 24 KB` 压缩限制。
* **代价与约束**：单批次最大意图与边数量需设置显式上限常量（如 `MAX_ACCOUNTS_PER_BATCH = 64`、`MAX_INTENTS_PER_BATCH = 128`）以保证最坏情况下的区块 Gas 上限确定可控。
