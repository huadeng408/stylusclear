# TKT-002：统一出清价批量拍卖、多抵押品组合保证金与三不变量终审门禁

* **Status**: `completed`
* **Spec**: [`SPEC-001`](../specs/SPEC-001-stylusclear-batch-clearing-engine.md)
* **Blocked by**: `TKT-001`
* **Testing Seam**: `Seam S1`

## 交付行为（Vertical Slice Behavior）

1. 实现离散候选价集合上的 `统一出清价格` `批量拍卖出清`（最大化成交量 → 最小化不平衡量 → 最贴近 `参考标记价格` 确定性平局裁决），以及无灰尘泄漏的按限价优先级与比例配额分配。
2. 实现多资产 `估值折扣率`（`Floor` 舍入）与 `组合净敞口` / `初始保证金要求` / `维持保证金要求`（`Ceil` 舍入）计算。
3. 串联“先 `多边环路压缩` 释放锁死头寸 → 再 `批量拍卖出清` → 最终核验 `资产守恒` + `限价个体理性` + `健康度单调性`”全流程，支持违例 `原子拒止回滚`。

## 验收判据（Acceptance Criteria）

* 在“环路压缩前保证金不足、环路压缩释放锁死应收后保证金达标”的关键业务场景中批次顺利出清；
* 任何买单出清价高于限价、卖单出清价低于限价、或新开仓后低于初始保证金线的批次 100% 触发对应错误码并整批回滚。
