## 1. Problem Statement & Why Solver-Less On-Chain WASM?

Intent protocols (CoW Protocol, UniswapX) rely on off-chain solvers to compute settlements, creating centralized solver censorship risk and requiring complex on-chain verification. Meanwhile, executing multilateral graph cycle elimination (`O(V²) 2-Origin BFS` over `N x N` directed obligation matrices with up to `62` chord cycles) plus multi-candidate Uniform Clearing Price Batch Auctions (`UCPBA`) directly in EVM Solidity incurs prohibitive memory/stack gas costs ([Stylus VM Differences](https://docs.arbitrum.io/stylus/concepts/vm-differences)).

`StylusClear` eliminates off-chain solver trust entirely: the **canonical O(V²) 2-Origin BFS cycle compression + monotonic UCPBA + portfolio margin engine runs 100% on-chain inside Arbitrum Stylus WASM linear memory**, flushing only net balance deltas to storage.

## 2. v1.0.0 Hardened Protocol Architecture

Aligned with the [Stylus Activation Pause Notice](https://docs.arbitrum.io/notices/stylus-activation-pause-notice) and [[Constitutional] AIP: Stylus Activation Contract (`AIP-31605`)](https://forum.arbitrum.foundation/t/constitutional-aip-stylus-activation-contract/31605), `StylusClear` targets **Arbitrum Sepolia (`421614`)**, **[Robinhood Chain Testnet (`46630`)](https://docs.robinhood.com/chain/connecting/)** ([USDG Stablecoin Track](https://grants.watch/programs/arbitrum-stablecoin-growth-program)), and **Arbitrum Orbit L3 (`42161405`)**:

1. **Stage 1 — Authenticated Address-Canonical Cycle Netting + Zero-Allocation Bypass**: Validates `PreRegisteredLedger`, `DirectDebtor`, and EIP-712 `ObligationAttestation` edges with exact `SECP256K1_HALF_N = N >> 1` (`0x7fff...5d576e7357a4501ddfe92f46681b20a0`) and `r < N` checks; skips 2 MiB matrix allocation under `mini-alloc` when `obligations` is empty; eliminates up to `62` overlapping chord cycles deterministically.
2. **Stage 2 & 3 — Wash-Free Monotonic UCPBA & Selective Nonce Consumption**: Rejects same-trader opposite-side wash intents (`InvalidIntent`), enforces constant `MIN_INTENT_AMOUNT_WAD = 10^9` step size so aggregate demand/supply curves are strictly monotonic (blocking 1-Gwei price-grid hijacking while routing real sub-WAD ceiling-minus-floor spread dust into `feeVault`), filters candidates strictly inside the `±max_price_deviation_bps` band (`4`-sig-fig `ref_tick`) with candidate deduplication in both Rust and Solidity, and consumes EIP-712 nonces **only on filled intents** (`filled_base_wad > 0`).
3. **Stage 4 — Conservation, Margin, Proportional Underwater Liquidation (`250 bps`) & Dust Closure**: Verifies checked `I256` zero-sum conservation before rejecting empty/zero-settlement batches (`InvalidIntent`), enforces `haircut_bps < 10,000` and net-equity monotonicity, and provides permissionless `liquidate()` (`health_wad < 0`, `LIQUIDATION_BONUS_CAP_BPS = 250` = `min(mm_bps / 2, 250 bps) with mm_bps >= 2`, two-step 512-bit overflow-free seizure with proportional ceiling debt back-calculation when `raw_seize > avail_coll` per `ADR-0010`), `sweepDustToFeeVault(assetId)` for `<18`-decimal ERC-20 custody closure, and oracle-independent `invalidateNonces` / `revokeObligation`.
4. **Four-Asset Sepolia / Robinhood RWA Parity & Reproducible WASM 1.0 Lock**: Configures 4 standard collateral/clearing slots (`0: USDC/USDG 6d`, `1: WETH 18d`, `2: ARB 18d`, `3: NVDAx/RWA 18d @ $140`), enforces `.cargo/config.toml` (`-reference-types,-simd128` per [Rust 1.82+ WASM Target Notice](https://blog.rust-lang.org/2024/09/24/webassembly-targets-change-in-default-target-features/) and [Stylus WebAssembly Spec](https://docs.arbitrum.io/stylus/concepts/webassembly)), `Cargo.lock` + `cargo build --locked`, `Host::msg_reentrant()` ([Stylus Rust SDK Guide](https://docs.arbitrum.io/stylus/reference/rust-sdk-guide)), immutable `token`/`decimals` asset registration, `SafeERC20` optional-bool return handling, and Solidity `balanceOf` delta verification.
